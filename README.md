# 🎙️ AI Voice Assistant

A Python-based AI Voice Assistant powered by Grok AI that enables natural voice interactions. The assistant listens to user input, processes queries using AI, and responds using a customized voice for a seamless conversational experience.

## 🚀 Features

* Voice-based interaction
* AI-powered responses using Grok
* Speech-to-Text conversion
* Text-to-Speech responses
* Custom voice output
* Real-time conversation handling

## 🛠️ Technologies Used

* Python
* Grok API
* Speech Recognition
* Text-to-Speech (TTS)
* PyAudio

## 📋 How It Works

1. The user speaks through the microphone.
2. Speech is converted into text.
3. The query is sent to Grok AI.
4. Grok generates a response.
5. The response is converted to speech.
6. The assistant speaks the answer back to the user.
